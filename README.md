# MedAxis – Smart Patient Queue & Emergency Triage System

## 📌 Project Description

MedAxis is a web-based hospital management prototype designed to simplify patient registration, emergency triage, and queue management. It helps healthcare staff organize patients according to urgency, monitor waiting queues, and manage patient records from registration to consultation.

The system provides a centralized dashboard for tracking patient status, maintaining visit history, managing reports, and viewing operational information. It aims to improve hospital workflow and help staff manage patient flow more efficiently.

## ✨ Key Features

* **Patient Registration:** Register patients and record their details, symptoms, and department.
* **Emergency Triage:** Categorize patients by urgency to support queue prioritization.
* **Smart Queue Management:** Display priority-sorted patient queues and illustrative waiting-time estimates.
* **Patient Directory:** Search and review registered patient records.
* **Patient History:** Maintain visit summaries and organize patient reports.
* **Dashboard & Notifications:** View operational information and manage notifications.
* **CSV Export:** Export patient queue and registration data for reporting.
* **Local Data Storage:** Store demo records in the browser for demonstration purposes.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage

## 🎯 Objective

To develop a user-friendly hospital workflow prototype that demonstrates how digital patient registration, urgency-based queue organization, and centralized record management can support more efficient hospital operations.

## ⚠️ Disclaimer

This project is a demonstration prototype, not a certified clinical triage system. Triage categories and waiting-time estimates are illustrative and must not replace professional medical judgment. Data is stored locally in the browser; the project is not intended for real patient information or production healthcare use.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open the main HTML file in a modern web browser.
4. Explore the dashboard and test the available features using demo data.
